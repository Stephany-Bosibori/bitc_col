File Transfer Protocol

Moving Large Data

While HTTP is great for viewing web pages, FTP is optimized for moving files between a client and a server.

Usage

Web developers use FTP to "upload" their website files from their local computer to a web server so the public can see them.

Security

Standard FTP is unencrypted. Most modern professionals use SFTP (Secure FTP) which uses SSH to encrypt the file transfer.
