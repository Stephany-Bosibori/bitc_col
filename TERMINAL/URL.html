Uniform Resource Locator (URL)

The GLobal System

A URL is the specific string of characters used to identify a resource on the web. Without a standardized addressing system, it would be impossible to find specific files among the billions hosted online.

Components

It consists of several parts: the protocol, the domain name, the port, and the path to the specific resource.
