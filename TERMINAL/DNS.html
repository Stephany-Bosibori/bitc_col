Domain Name System (DNS)

The Internet's Phone Book

DNS translates domain names into IP addresses that computers use to identify each other. Computers communicate using numbers (IP addresses), but humans remember names. DNS is the system that bridges this gap.

The Lookup Process

When you type "https://www.google.com/search?q=google.com," your computer contacts a DNS Resolver. The resolver looks up the name in a massive distributed database and returns the IP address (e.g., $142.250.190.46$).

Significance

DNS allows websites to change their physical servers (and IP addresses) without users ever needing to learn a new address.
