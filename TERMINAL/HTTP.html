Hypertext Transfer Protocol (HTTP)

The rules of Engagement

HTTP is the "stateless" protocol used for transmitting web pages. "Stateless" means the server does not remember the client between requests unless cookies are used.

Request and Response

Every interaction on the web is an HTTP Request (from you) followed by an HTTP Response (from the server).
